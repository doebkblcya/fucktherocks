# FuckTheRocks — 第一版产品定义

## 1. 产品定位

FuckTheRocks 是一个用时间化流派网络讲述摇滚发展路线与类型关系的中文网站。

历史和分类不是两个独立产品模块，而是同一份知识网络的两个观察维度：

- **时间视角**：沿年代查看重要阶段、历史节点及其相关流派；
- **关系视角**：查看流派之间的起源、衍生与融合。

第一版把两者放进同一个探索体验：用户既能顺着年代阅读，也能从任意流派沿关系继续追踪。

网站以中文叙事为主，乐队、流派和专辑等专名保留原文。

## 2. 第一版结构

### 首页

首页是品牌宣传与视觉体验，不承担内容陈列任务。

- 用高冲击力主视觉表达摇滚、时间与流派关系；
- 通过滚动和交互完成一段短而完整的品牌体验；
- 最终引导用户进入“探索”；
- 文案少而准确，不堆叠内容卡片。

### 探索

探索页是第一版唯一的内容主页面，以年代为骨架，将历史节点与流派关系组织在同一张可探索网络中。

- 年代是主轴；
- 历史事件和流派都锚定在相应时间位置；
- 流派之间使用明确区分的起源、衍生、融合和影响关系；
- 用户可以顺着年代连续阅读，也可以聚焦一个流派并查看它的直接关系；
- 搜索、分支筛选和年代定位只改变观察范围，不把用户带离探索页；
- 页面同时提供等价的文字结构，保证移动端、键盘和图谱降级时仍可浏览。

具体节点和代表专辑属于内容编辑工作，不在产品规划阶段预先限定。

### 节点详情

历史事件或流派被选择后，在探索页内展开详情，不建立第一版独立详情路由。

- 历史事件显示背景、变化、影响、相关流派和代表专辑；
- 流派显示中文名、原文名、定义、成形时间与地点；
- 展示直接来源、融合、影响、后继与相关场景；
- 展示相关历史事件和代表专辑；
- 关闭详情后返回原来的年代、缩放和筛选状态；
- 节点可使用 URL 参数或锚点形成可分享的深链接，但仍属于同一页面。

## 3. 信息架构

~~~text
/                  首页
/explore           发展路线与分类网络
~~~

顶部导航只保留首页和探索。首页使用一个明确的“进入探索”行动入口。

## 4. 内容关系

第一版围绕四类内容实体组织：

- **年代**：发展路线的分段；
- **历史节点**：某一时期的重要变化；
- **流派**：分类图中的核心实体；
- **代表专辑**：用于说明时代或流派的关联资料。

历史节点和流派通过引用互相连接；代表专辑可被多个历史节点或流派复用。页面是否合并不改变底层实体的独立性。

## 5. 第一版完成标准

- 首页形成鲜明、完整且可进入核心内容的品牌体验；
- 探索页能从摇滚根源连续浏览到当代；
- 同一页面能清楚表达主要流派的起源、衍生、融合与历史位置；
- 用户可在时间阅读与关系追踪之间自然切换，不需要理解两个栏目之间的区别；
- 每个主要流派都能在页面内打开详情，并准确返回原浏览位置；
- 桌面和移动设备都能完成核心浏览；
- 高级视觉效果不可用时，内容与导航仍然可用。
