# FuckTheRocks — 产品文档

> 本文件是全部设计文档的锚点。定位、用户、站点结构、分类学体系与内容策略均在此定义，`requirements.md` / `tech-design.md` / `roadmap.md` 均从本文件派生。

## 1. 产品定位

**一句话**：FuckTheRocks 是一个摇滚音乐知识网站，系统化地记载摇滚乐的发展史、专辑收录与流派分类学。

**产品形态**：综合内容站，融合三种知识表达方式——

- **百科**：乐队 / 艺术家、专辑、流派的结构化词条；
- **时间线**：以年代为轴的发展史，串联事件、乐队与代表专辑；
- **数据库**：可检索、可交叉引用的关系型内容（乐队 ↔ 专辑 ↔ 流派 ↔ 年代）。

**品牌**：对外展示名 `FuckTheRocks`，域名 `fuckthe.rocks`（已购入）。

**技术形态**：静态站（Astro + Markdown/MDX），纯只读，无用户系统、无后端登录态。

## 2. 目标用户

| 用户群 | 特征 | 核心诉求 |
| --- | --- | --- |
| 入门乐迷 | 对摇滚有兴趣但缺乏系统认知 | 按年代/流派系统地了解摇滚脉络 |
| 资深乐迷 | 已有积累，追求深度与准确性 | 查流派溯源、专辑脉络、乐队沿革 |
| 音乐研究者/内容创作者 | 需要可靠的结构化资料 | 交叉检索、引证、关联发现 |

## 3. 核心价值

1. **系统化的摇滚发展史**：从 50 年代起源到当代，全流派通史，而非零散词条；
2. **严谨的流派分类学**：自由网状结构，能表达流派的衍生与融合（如 朋克 + 金属 → 鞭挞金属）；
3. **可交叉引用的内容网**：乐队、专辑、流派、年代四者互相串联，而非信息孤岛；
4. **中文友好**：中文叙事 + 专名（乐队/专辑/流派）保留原文。

## 4. 内容范围

- **时间跨度**：1950s 起源 → 当代，覆盖全部主要子流派；
- **流派**：经典摇滚、重金属、朋克、另类、前卫、后摇、独立、硬核等及其子流派；
- **乐队/艺术家**：里程碑级乐队为主，兼顾各流派代表；
- **专辑**：代表专辑（里程碑 + 各流派代表作），含曲目、厂牌、发行信息。

## 5. 站点地图（信息架构）

```
首页 Home         门户入口 + 精选（年代导航 / 流派速览 / 代表专辑）
├─ 发展史 History   时间线视图，按年代切分，串联事件、乐队、代表专辑
├─ 分类学 Taxonomy  流派网状图谱，每个流派页：定义、起源、衍生、融合来源、代表乐队/专辑
├─ 乐队 Artists     词条页：成员、活跃年代、风格、流派归属、关联专辑
├─ 专辑 Albums      专辑页：曲目、发行信息、厂牌、流派标签、关联乐队
└─ 检索 Search      Pagefind 全文/标签检索，跨乐队、专辑、流派、年代
```

## 6. 分类学体系（站点特色）

- **结构**：自由网状深度——不预设层级数，用有向图自由关联；
- **流派节点**（Genre）包含：名称（中文 + 原文）、别名、定义、起源年代与地点、父流派、衍生子流派、融合来源（可多个）、代表乐队、代表专辑、关键事件；
- **关键设计**：流派既可成树（摇滚 → 重金属 → 鞭挞金属），也可网状融合（朋克 + 金属 = 鞭挞金属），故节点需支持 **多父 / 多来源融合**，而非单一 parent。

## 7. 内容策略

- **结构化数据**（乐队名、成员、专辑、曲目、发行年份、厂牌、风格标签）：从 **MusicBrainz** 导入（CC0 许可，无版权风险）；
- **叙事内容**（摇滚发展史、流派中文定义、专辑在史中的定位点评、乐队译名与介绍）：**人工撰写**，可参考 Wikipedia/Wikidata 但不直接照搬（规避 CC BY-SA 传染）；
- **Discogs**：仅作人工查证参考，不批量导入（许可限制大规模镜像）；
- **语言**：中文为主，乐队名/专辑名/流派名保留原文（如 Led Zeppelin、Grunge）。

## 8. MVP 范围

首版（MVP）落地以下页面：

1. **首页**：门户入口 + 精选内容；
2. **分类学**：流派网状图谱与流派词条页；
3. **发展史**：年代时间线；
4. **乐队 / 专辑词条页**：结构化详情；
5. **检索**：Pagefind 站内搜索。

## 9. 非 MVP（暂缓 / 后续）

- 用户系统、云端收藏、评论（定位为纯只读静态站，暂不规划）；
- 曲目级独立详情页（曲目先并入专辑页）；
- 乐评、社区、UGC；
- 多语言（中英双语全量条目）。

## 10. 成功指标（初步）

- 流派分类学覆盖主要摇滚子流派，结构可自洽地表达融合关系；
- 发展史时间线能从起源连贯走到当代；
- 里程碑乐队/专辑词条数据完整、交叉引用可用；
- 站内检索能按乐队/专辑/流派/年代准确定位内容。
