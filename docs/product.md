# FuckTheRocks — 第一版产品定义

## 1. 产品定位

FuckTheRocks 是一个用视觉体验和时间化关系网络讲述摇滚发展路线与类型关系的中文网站。

它不是传统百科栏目集合。历史和分类是同一份知识网络的两个观察维度：

- **时间视角**：沿年代查看重要阶段、事件、流派与代表专辑；
- **关系视角**：从任意流派追踪直接来源、衍生、融合、影响和场景承接。

首页负责让用户感受到摇滚在时间中的累积、分化与重新连接；探索页负责让用户真正阅读和追踪这些关系。网站以中文叙事为主，乐队、流派、专辑和作品等专名保留原文。

## 2. 第一版页面

### 2.1 首页：3D 专辑画廊

首页是品牌入口，不承担百科式内容陈列。

- 第一版先用 30 张跨年代真实专辑封面验证球面螺旋，后续增减以画面密度和内容必要性为准；
- 专辑按照时间而非随机顺序组织，让三维画廊成为摇滚历史的视觉序章；
- 全屏场景以观众位于球体内部为默认视角；用户通过原生页面滚动缓慢环视，镜头只做极小位移；
- 封面朝向球心，当前专辑进入视线中心并轻微向观众靠近；HTML 信息签只显示年份、流派线索、标题、艺人及一句介绍；
- 首页只保留品牌字样、当前专辑信息签和顶部“探索”入口，不放总说明段落或展览式导语；
- 高级效果不可用时，首页仍显示品牌字样、一张静态封面和入口。

首页不展示栏目卡片、文章列表、统计面板或完整专辑数据库。

### 2.2 探索页：时间化摇滚关系网络

探索页是第一版唯一的内容主页面。

- 11 段年代构成从根源到当代的纵向阅读骨架，不再只展示 1975—1994 年样本；
- 四条主要脉络和完整流派索引让用户直接看到有哪些声音、场景与相邻传统；
- 每个条目可行内展开定义、形成区间和有依据的来源／后续关系；
- 关系明确区分直接衍生、融合、影响、场景承接、市场化、复兴和并行；
- 单一搜索框与时间锚点帮助定位，不把用户带离探索页；
- 代表专辑暂留在内容资料中；当前探索页先把时间与流派讲清，不形成独立栏目；
- 页面本身就是可访问的文字结构，移动端和键盘用户无需图谱降级。

探索页不是一次性展示全部连线的巨型关系图。默认完整列出名称与时间，解释和关系按需展开；四条脉络只是阅读导航，不是互斥分类树。

### 2.3 基础错误页

错误页负责处理无效地址，并保持品牌体验完整。

- 明确显示页面不存在；
- 提供返回首页和进入探索两个恢复入口；
- 延续白底黑字和杂志式排版；
- 不加载 Three.js、关系网络或其他重型客户端代码。

## 3. 页面内详情

流派被选择后，在探索页内展开详情，不建立独立详情路由。历史事件目前作为时间段的关键变化呈现，尚未建立独立事件详情。

- 流派显示名称、类型、形成区间和简短定义；
- 优先展示有依据的来源、融合、影响、后继与相关场景；
- 时间链中的名称可以跳到索引并展开对应条目；
- 使用查询参数形成可分享状态，例如 `/explore?genre=post-punk`，但仍属于同一页面。

桌面与移动端统一使用行内展开，避免额外侧栏或底部面板打断阅读。

## 4. 信息架构

~~~text
/                         首页
/explore                  探索页
/explore?genre=post-punk  探索页的可分享选中状态
/404                      基础错误页
~~~

顶部导航只保留品牌与单一跨页入口；探索页提供返回首页、时间链／索引锚点和一个搜索框。

## 5. 核心使用路径

### 视觉进入

~~~text
进入首页 → 在球内滚动环视专辑 → 看到年代变化 → 进入探索
~~~

### 时间阅读

~~~text
进入探索 → 定位年代 → 阅读历史节点 → 打开相关流派或专辑
~~~

### 关系追踪

~~~text
搜索或选择流派 → 聚焦直接关系 → 打开相邻节点 → 沿关系继续浏览
~~~

## 6. 内容实体

第一版围绕四类实体组织：

- **年代**：发展路线的分段和页面阅读骨架；
- **历史节点**：某一时期的重要变化、场景或媒介事件；
- **流派**：关系网络的核心实体；
- **代表专辑**：连接时代、流派和听觉示例的可复用资料。

历史节点和流派通过稳定 ID 互相引用；代表专辑可被首页、多个历史节点和多个流派复用。页面合并不等于数据混成一张表。

## 7. 第一版不做

- 不保留独立的“发展史”“分类学”“乐队”“专辑”和“搜索”页面；
- 不为每个流派、乐队或专辑生成独立详情页；
- 不把首页做成内容卡片集合；
- 不在探索页默认展开全部节点和全部关系；
- 不依赖自动播放声音建立体验；
- 不把现有旧版页面、布局、配色和组件作为设计或工程基础；
- 不以“收录所有摇滚流派”为第一版完成条件。

## 8. 第一版完成标准

- 首页在完整、简化和静态模式下都能建立品牌印象并进入探索；
- 3D 专辑画廊具有明确的时间秩序，不是随机图片球；
- 探索页能从摇滚根源连续浏览到当代；
- 同一页面能清楚表达主要流派的历史位置和直接关系；
- 用户可以在时间阅读与关系追踪之间自然切换；
- 搜索、行内详情、流派深链接与浏览器前进后退可用；
- 桌面、触控设备、键盘和减少动态效果模式都能完成核心浏览；
- 无 WebGL 或无 JavaScript 时不会出现空白页面；
- 无效地址能够进入可恢复的基础错误页。
