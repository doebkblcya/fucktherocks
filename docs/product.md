# FuckTheRocks — 第一版产品定义

## 1. 产品定位

FuckTheRocks 是一个用视觉体验和时间化关系网络讲述摇滚发展路线与类型关系的中文网站。

它不是传统百科栏目集合。历史和分类是同一份知识网络的两个观察维度：

- **时间视角**：沿年代查看重要阶段、事件、流派与代表专辑；
- **关系视角**：从任意流派追踪直接来源、衍生、融合、影响和场景承接。

首页负责让用户感受到摇滚在时间中的累积、分化与重新连接；探索页负责让用户真正阅读和追踪这些关系。网站以中文叙事为主，乐队、流派、专辑和作品等专名保留原文。

## 2. 第一版页面

### 2.1 首页：3D 专辑画廊

首页是品牌入口，不承担百科式内容陈列。

- 在白色三维空间中，将 24—40 张代表专辑封面排列在球面或球面螺旋上；
- 专辑按照时间而非随机顺序组织，让三维画廊成为摇滚历史的视觉序章；
- 用户通过原生页面滚动驱动画廊旋转和轻微镜头变化；
- 当前进入视野中心的专辑显示年份、艺人和流派，其余封面保持克制；
- 页面文字保持少而准确，只有一个主要行动入口：“进入探索”；
- 高级效果不可用时，首页仍显示完整品牌文案、静态视觉和入口。

首页不展示栏目卡片、文章列表、统计面板或完整专辑数据库。

### 2.2 探索页：时间化摇滚关系网络

探索页是第一版唯一的内容主页面。

- 年代是纵向阅读骨架；
- 历史事件和流派锚定在相应时间位置；
- 流派之间明确区分直接衍生、融合、影响和场景承接；
- 默认状态适合连续阅读，选择流派后转为局部关系聚焦；
- 搜索、分支筛选和年代定位只改变观察范围，不把用户带离探索页；
- 代表专辑用于帮助用户听见某一阶段或关系，不形成独立栏目；
- 页面提供等价的文字结构，保证移动端、键盘和图谱降级时仍可浏览。

探索页不是一次性展示全部节点的巨型关系图。默认只呈现主干和当前时间附近的内容，用户通过选择节点逐步展开直接关系。

### 2.3 基础错误页

错误页负责处理无效地址，并保持品牌体验完整。

- 明确显示页面不存在；
- 提供返回首页和进入探索两个恢复入口；
- 延续白底黑字和杂志式排版；
- 不加载 Three.js、关系网络或其他重型客户端代码。

## 3. 页面内详情

历史事件或流派被选择后，在探索页内打开详情，不建立独立详情路由。

- 历史事件显示背景、变化、影响、相关流派和代表专辑；
- 流派显示中文名、原文名、定义、形成时间与地点；
- 优先展示直接来源、融合、影响、后继和相关场景；
- 展示相关历史事件和少量代表专辑；
- 关闭详情后恢复之前的年代、筛选、视口和键盘焦点；
- 使用查询参数形成可分享状态，例如 `/explore?genre=post-punk`，但仍属于同一页面。

桌面端详情使用侧栏；移动端使用可关闭的底部面板或行内展开。

## 4. 信息架构

~~~text
/                         首页
/explore                  探索页
/explore?genre=post-punk  探索页的可分享选中状态
/explore?era=1980s        探索页的可分享年代状态
/404                      基础错误页
~~~

顶部导航只保留品牌与“探索”。首页结尾提供明确的“进入探索”入口；探索页提供返回首页、搜索、年代定位和分支筛选。

## 5. 核心使用路径

### 视觉进入

~~~text
进入首页 → 滚动浏览专辑球面 → 看到年代变化 → 进入探索
~~~

### 时间阅读

~~~text
进入探索 → 定位年代 → 阅读历史节点 → 打开相关流派或专辑
~~~

### 关系追踪

~~~text
搜索或选择流派 → 聚焦直接关系 → 打开相邻节点 → 沿关系继续浏览
~~~

## 6. 内容实体

第一版围绕四类实体组织：

- **年代**：发展路线的分段和页面阅读骨架；
- **历史节点**：某一时期的重要变化、场景或媒介事件；
- **流派**：关系网络的核心实体；
- **代表专辑**：连接时代、流派和听觉示例的可复用资料。

历史节点和流派通过稳定 ID 互相引用；代表专辑可被首页、多个历史节点和多个流派复用。页面合并不等于数据混成一张表。

## 7. 第一版不做

- 不保留独立的“发展史”“分类学”“乐队”“专辑”和“搜索”页面；
- 不为每个流派、乐队或专辑生成独立详情页；
- 不把首页做成内容卡片集合；
- 不在探索页默认展开全部节点和全部关系；
- 不依赖自动播放声音建立体验；
- 不把现有旧版页面、布局、配色和组件作为设计或工程基础；
- 不以“收录所有摇滚流派”为第一版完成条件。

## 8. 第一版完成标准

- 首页在完整、简化和静态模式下都能建立品牌印象并进入探索；
- 3D 专辑画廊具有明确的时间秩序，不是随机图片球；
- 探索页能从摇滚根源连续浏览到当代；
- 同一页面能清楚表达主要流派的历史位置和直接关系；
- 用户可以在时间阅读与关系追踪之间自然切换；
- 搜索、筛选、节点详情、深链接与浏览器前进后退可用；
- 桌面、触控设备、键盘和减少动态效果模式都能完成核心浏览；
- 无 WebGL 或无 JavaScript 时不会出现空白页面；
- 无效地址能够进入可恢复的基础错误页。
