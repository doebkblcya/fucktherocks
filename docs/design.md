# FuckTheRocks — 第一版体验设计

## 1. 设计方向

第一版采用白底黑字的极简现代杂志风，并借用古典雕塑摄影的空间品质：大量留白、明确比例、石膏般的中性色和被当作藏品陈列的对象。界面只保留完成任务必需的元素；解释性文字进入用户主动打开的详情。

“古典雕塑感”描述的是构图、光线和空间，不要求页面直接堆放希腊雕像素材。摇滚感来自专辑封面、关系结构、文字态度和运动节奏，不依赖撕纸、火焰、霓虹、唱片机或效果器面板等惯用符号。

首页和探索页共享同一套编辑设计语言，但承担不同任务：

- 首页是高沉浸、低信息密度的三维品牌场景；
- 探索页是低视觉密度、可逐步展开的二维知识界面；
- 错误页是最轻量的恢复界面。

现有旧版页面、布局、颜色和组件不作为设计参考。

## 2. 视觉基础

### 2.1 色彩

初始色彩方向如下，具体数值在原型阶段根据屏幕与封面实测微调：

~~~text
背景         #F2F1ED  微暖石膏白
主要文字     #111111  近黑
辅助文字     #77736C  暖灰
结构线       #CBC8C0  浅灰
浮层背景     #E8E6E0  浅石色
强调色       来自当前专辑封面或选中关系
~~~

页面不预设全站高饱和品牌色。首页当前专辑封面可以成为主要色彩来源；探索页关系类型主要依靠线型、粗细、箭头和标签区分，颜色只做辅助，不能成为唯一编码。

### 2.2 字体与排版

- 标题使用高对比、具编辑感的展示字体或经过验证的现代无衬线字体；
- 正文使用高可读性的中文字体系统；
- 英文流派名、专辑名、年份和编号使用更紧凑的排版；
- 字号、字重、字距和留白建立明显层级，不依赖卡片阴影区分内容；
- 中文正文保持正常阅读宽度，长段文字不覆盖在 WebGL 画布中；
- 最终字体在原型阶段根据中文覆盖、授权、加载体积和跨平台表现确定。

### 2.3 图形语言

- 细线和年份负责建立时间感，不叠加装饰性编号、口号或辅助标签；
- 专辑封面保持原始比例，不裁切成圆形或异形；
- 阴影轻且柔和，物体像悬浮印刷品，不像厚重 UI 卡片；
- 动效强调惯性、聚焦与空间变化，避免持续抖动、频闪和无意义噪点；
- 非当前内容保持低对比或灰度，当前内容恢复清晰度和色彩。

## 3. 首页：3D 专辑画廊

### 3.1 页面任务

首页只负责建立品牌印象，并把用户送往探索页。它不是专辑目录，也不承担完整知识阅读。

~~~text
┌──────────────────────────────────────────┐
│ FUCKTHEROCKS                       探索  │
│                                          │
│                                          │
│          观众位于专辑球面内部            │
│       封面围绕视线分布并依次进入焦点       │
│                                          │
│  1956  当前专辑 · 一句话介绍               │
└──────────────────────────────────────────┘
~~~

首页保持一段连续体验，不拆成多个常规内容区块。

### 3.2 专辑球面

- 第一轮使用 30 张真实代表专辑，按 1956—2014 排序；
- 封面分布在球面或接近球面的螺旋路径上；
- 排列顺序必须表达时间：早期根源位于路径起点，随后依次进入各年代；
- 封面不是随机装饰，当前视野必须能对应一个年份或时间区间；
- 相机位于球体内部附近，封面作为朝向球心的独立平面；
- 封面有微小半径差，镜头有极轻微位移，以透视和视差显示前后深度；聚焦封面稍向观众靠近，并显示克制的纸边和柔和阴影；
- 低对比的经纬线暗示空间曲率，不显示外视球体轮廓，也不能盖过封面；
- 当前专辑的年份、流派线索、标题、艺人和一句简短介绍使用 HTML 显示在画布之外；只介绍当前一张，不为周围封面叠加标签；
- 专辑封面是视觉导航，不在第一轮承担单张专辑详情入口。

球面只展示经过编辑选择的代表专辑，不追求覆盖所有节点。

### 3.3 滚动与相机

- 保留浏览器原生纵向滚动，不拦截滚轮制造虚假滚动；
- 页面滚动进度映射为球内的观看方向、当前年代和当前专辑；
- 镜头沿按时间排列的球面路径缓慢环视，不翻滚或高速推进；
- 镜头始终位于球体内部附近，只做很小的平移以保留真实视差；
- 桌面指针只提供几度以内的轻微倾斜，不改变当前专辑或时间定位；
- 触控设备使用同一滚动叙事，不要求拖拽完整三维球体；
- 页面离开可视区域或标签页隐藏时暂停渲染；首屏只请求视线附近的纹理。

### 3.4 文字与入口

WebGL 画布只负责视觉场景。以下内容必须使用真实 HTML：

- 品牌名称；
- 当前年份与当前专辑信息；
- 顶部“探索”入口；
- 无障碍说明与降级内容（可在视觉上隐藏）。

入口在加载期间、静态模式和页面结尾始终可用，不能等待动画完成后才出现。首页不使用杂志封面副标题、展览说明或额外结尾文案。

## 4. 探索页：完整时间链与分类索引

### 4.1 默认阅读

探索页以文字优先，不把关系线铺满默认画面。页面依次呈现：

1. 四条主要脉络的快速入口；
2. 从根源到当代的 11 段纵向时间链；
3. 按脉络整理的 95 个流派、场景和相邻传统索引。

每段时间显示时间范围、发生的主要变化和少量关键名称。流派索引直接露出全部名称与形成区间；用户展开条目时，才看到定义及来源、融合、后续等文字关系。四条脉络只是导航，不宣称构成互斥分类树。

### 4.2 流派详情与关系

使用原生 HTML `details` 行内展开，桌面与移动端保持同一阅读顺序：名称、形成区间、类型、简短定义、来源与后续。关系明确标记为衍生、融合、影响、场景承接、市场化、复兴或并行，不用单一箭头暗示所有关系都是父子关系。弱证据关系暂不进入页面。

时间链中的流派名称可跳转并展开索引条目；查询参数 `/explore?genre=post-punk` 保留可分享状态。无 JavaScript 时，时间链、索引和原生详情仍可阅读。

### 4.3 搜索

第一版只保留一个查找框，匹配中英文名称、形成区间和简短定义；输入时筛掉不匹配的行，显示结果数量和空结果提示。清空输入后恢复全部条目。不增加多级下拉、线型图例或默认铺开的网络图。

## 5. 移动端

移动端保留与桌面相同的时间链和索引内容，以单列排版阅读，不需要缩放图谱。

### 首页

- 降低渲染分辨率，保持同一份精简封面集合；
- 不增加额外视差或相机运动；
- 保留原生滚动、当前年份、专辑信息和探索入口；
- 设备能力不足时直接采用静态杂志式封面构图。

### 探索页

- 年代仍是纵向主轴；
- 四条脉络改为两列入口，索引条目单列排列；
- 详情原位展开，不需要底部面板、横向拖拽或双指缩放；
- 页面内跳转和单一搜索框保持可见、可操作。

## 6. 基础错误页

错误页延续全站排版，但保持完全静态。

~~~text
404

页面不存在。

[ 返回首页 ]  [ 进入探索 ]
~~~

不在错误页加载 3D 场景，不使用复杂动画掩盖错误信息。

## 7. 动效与能力模式

页面启动时根据 WebGL 支持、设备表现、触控环境和减少动态效果设置选择模式。模式选择不依赖单一设备型号判断。

| 模式 | 首页 | 探索页 |
| --- | --- | --- |
| 完整 | Three.js 球内画廊、连续缓动的环视与轻微指针倾斜 | 完整时间链、索引、搜索和展开详情 |
| 简化 | 限制分辨率、低对比远景和低运动量 | 同一 HTML 内容，减少平滑滚动 |
| 静态 | 一张真实封面的静态构图、品牌与入口 | 同一 HTML 时间链、索引和原生详情；搜索不增强 |

`prefers-reduced-motion: reduce` 默认进入静态或接近静态的体验。用户仍能访问全部信息和操作。

任何模式下都必须：

- 保持主要操作可点击；
- 不因纹理或脚本加载失败而出现空白；
- 不劫持滚动或阻断浏览器导航；
- 保持键盘焦点清晰可见；
- 避免频闪和突然的大幅位移；
- 不自动播放声音。

## 8. 响应式与可访问性

- 正文和控件满足 WCAG 2.2 AA 对比度；
- 所有功能支持键盘操作；
- 触控目标不小于 44 × 44 像素；
- Canvas 对辅助技术隐藏，关键信息保留在 HTML 中；
- 探索页本身使用可访问的文字时间链与索引；
- 历史节点使用原生可展开语义或等价实现；
- 当前选中状态不只依赖颜色表达；
- 动态更新的专辑或节点信息避免形成高频读屏播报；
- 字体、封面或 JavaScript 未加载时仍保留可理解的页面结构。

## 9. 需要制作的关键设计状态

第一版只有三个路由，但至少需要验证以下界面状态：

1. 首页完整 WebGL 状态；
2. 首页简化和静态状态；
3. 探索页默认时间阅读状态；
4. 探索页选中流派与详情状态；
5. 探索页搜索状态；
6. 探索页文字降级状态；
7. 移动端首页；
8. 移动端探索及行内详情；
9. 基础错误页。

## 10. 设计约束

- 首页不堆叠常规内容卡片；
- 专辑球面必须表达时间，不做随机图片装饰；
- 探索页默认列出所有名称，但不铺设关系线或同时展开全部说明；
- 不把每个区块都做成独立特效；
- 不让 3D 场景承载必须阅读的正文；
- 不为视觉效果牺牲导航、性能、对比度或设备兼容；
- 不将旧版页面的临时样式迁移到新设计系统。
