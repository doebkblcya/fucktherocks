# FuckTheRocks — 第一版体验设计

## 1. 设计方向

保留复古黑胶车库风：奶油纸底、炭黑文字、砖红强调、粗衬线标题和轻微印刷质感。

设计不把“复古”当作装饰主题，而把黑胶唱片的结构用于表达内容：

- 唱片旋转对应时间推进；
- 唱针落槽对应进入一段历史；
- 唱片沟槽延伸为发展路线；
- 沟槽分叉形成流派关系图。

大胆的视觉表达集中在首页。探索页保持清晰、可读，但让时间轴和关系线本身承担视觉识别。

## 2. 页面职责

### 首页：视觉封面

首页的唯一任务是建立品牌印象，并把用户送往“探索”。

~~~text
┌────────────────────────────────────┐
│ 品牌                               │
│                                    │
│          动态黑胶主场景            │
│       沟槽 → 时间线 → 流派网       │
│                                    │
│            [进入探索]              │
└────────────────────────────────────┘
~~~

首页不展示常规内容列表。它由一个经过编排的连续动效构成，而不是许多互不相关的动画：

1. 黑胶与唱针建立场景；
2. 滚动推动沟槽转化为发展轨迹；
3. 轨迹分叉为流派网络；
4. 单一“进入探索”入口出现。

### 探索：时间化流派网络

探索页把“先后顺序”和“流派关系”放在同一个空间里。默认状态强调时间阅读；用户选择流派后，页面转为关系聚焦，但不切换路由或进入另一个栏目。

- 年代固定为清晰的纵向主轴；
- 历史事件与流派节点锚定在相应年代，关系线可以跨越年代；
- 未选择节点时，用户可像阅读时间线一样连续向下浏览；
- 选择流派后突出直接来源、后继、融合和影响，弱化无关节点；
- 详情使用侧栏、浮层或行内展开，并保留当前年代和图谱位置；
- 父级、衍生和融合关系必须有不同的视觉编码；
- 移动端优先保证浏览和选择，不强行缩放完整大图；
- 页面同时提供搜索、年代定位、分支筛选和文字索引；
- 当前年代、选中节点与阅读进度始终可辨认。

~~~text
┌──────────┬─────────────────────────┐
│ 年代导航 │  时间主轴 + 流派节点网   │
│ 1950s    │       Blues ─┐          │
│ 1960s    │              ├→ Hard Rock│
│ 1970s    │ Psychedelic ─┘     │     │
│ 1980s    │                 Heavy Metal│
│          │                         │
│ 搜索/筛选│  [选中节点详情面板]      │
└──────────┴─────────────────────────┘
~~~

节点详情采用杂志式单栏或窄双栏排版。关系信息放在正文之前，代表专辑作为辅助材料穿插其中。桌面端优先使用侧栏，移动端使用可关闭的底部面板或行内展开。

## 3. 首页签名体验

首页的签名元素是“可进入的黑胶沟槽”，而不是单独旋转的唱片图标。

完整模式可使用 Canvas 或 WebGL 实现空间感、粒子和实时响应；基础模式使用 SVG 与 CSS 保留同一叙事。技术差异不能改变页面含义和入口位置。

声音遵循以下规则：

- 默认静音；
- 只能在用户主动操作后开启；
- 使用唱针、底噪和节点反馈等短音效；
- 始终提供可见的声音开关；
- 声音不承载独有信息。

## 4. 视觉基础

### 颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| Paper | #F5EFE0 | 页面底色 |
| Sleeve | #EFE6D0 | 内容区与卡片 |
| Vinyl | #1A1A1A | 主文字与唱片 |
| Faded Ink | #5C5548 | 次级文字 |
| Brick | #C0392B | 重点、链接和当前状态 |
| Caramel | #8B5E3C | 年代与辅助标记 |
| Rule | #D8CDB4 | 边框和分隔线 |

所有组件使用语义变量，不在组件内散落颜色值。

### 字体

- 展示字体：有机械感的粗衬线，用于品牌与大标题；
- 正文字体：高可读无衬线，用于长文；
- 数据字体：紧凑等宽或窄体，用于年代、编号和关系标签；
- 原文专名：使用衬线斜体，与中文叙事区分。

字体应实际随站点资源加载，不依赖用户设备恰好安装某种字体。

### 质感

- 纸张噪点只作为低对比背景；
- 印刷错位、磨损和划痕只用于大面积视觉场景；
- 内容区不使用影响阅读的重噪点；
- 专辑封面保留原色，用纸套式边框统一呈现。

## 5. 动效与能力降级

页面启动时检测浏览器能力、设备性能偏好和减少动态效果设置。

| 模式 | 表现 |
| --- | --- |
| 完整 | 实时场景、滚动驱动、指针响应和细节粒子 |
| 简化 | SVG/CSS 动效，减少粒子和实时计算 |
| 静态 | 静态主视觉、完整文案和正常入口；探索页退化为按年代组织的文字网络 |

任何模式下都必须：

- 保持主要操作可点击；
- 不因动画未加载而出现空白；
- 不让滚动劫持阻断页面；
- 保持键盘焦点可见；
- 避免闪烁和突然的大幅位移。

## 6. 响应式与可访问性

- 正文与控件满足 WCAG 2.2 AA 对比度；
- 所有功能支持键盘操作；
- 触控目标不小于 44 × 44 像素；
- 探索网络提供等价文字索引；
- 历史节点使用原生可展开语义或等价实现；
- 支持 prefers-reduced-motion；
- 动效画布对辅助技术隐藏，关键信息保留在 HTML 中；
- 移动端不复制桌面构图，而是保留同一叙事的简化版本。

## 7. 约束

- 首页不堆内容卡片；
- 不自动播放声音；
- 不把每个区块都做成独立特效；
- 不为视觉效果牺牲导航、正文或设备兼容；
- 黑胶语言必须承载时间或关系含义，不能只是装饰。
