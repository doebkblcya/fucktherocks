# 摇滚历史与分类学资料库

本目录用于整理第一版网站的内容资料。资料以用户提供的内容为主，联网检索只用于补充背景、核对事实和提供出处。

这里保存的是编辑资料，不直接作为网站运行数据。探索页第一轮已将主要节点、阶段和较有依据的关系转换到 `src/data/explore-*.json`；资料母稿仍标记为“待确认”，入站不等于所有字段已完成最终核验。

内容资料同时服务两个页面：

- 首页从 Album 数据中选择 24—40 张跨年代代表专辑，形成按时间排列的 3D 画廊；
- 探索页使用年代、历史节点、流派关系和代表专辑构成时间化网络。

基础错误页不读取内容资料。

## 总纲

- [`explorable-rock-map.md`](./explorable-rock-map.md)：新的探索页内容母稿，整合历史、分类、节点、关系、时间阶段和代表专辑，状态为“待确认”。
- [`explorable-rock-map-sources.md`](./explorable-rock-map-sources.md)：175 篇公众号文章的逐篇映射、原图校正账和外部证据目录。

## 当前入站范围

早期页面曾只使用 1975—1994 年的 16 节点切片；现在已扩展为 11 个阶段、95 个名称条目和 110 条 A/B 级文字关系。后续优先工作是逐条核对时间、类型、定义和关系来源，补强 2000 年后的地域与场景资料，并让代表专辑与流派稳定互引。C 级编辑假设关系仍留在资料母稿，不直接展示。

## 每篇资料的处理流程

1. 将用户发送的原文存入 raw，原则上不改写内容；
2. 判断资料对应的时间阶段、节点和关系；
3. 重组时间、地点、人物、流派、场景和专辑关系；
4. 联网核对容易出错或需要补充的事实；
5. 将网络补充与来源明确写入整理稿；
6. 标记不确定、存在争议或需要用户确认的内容；
7. 用户确认后将状态改为“可入站”。

## 编辑原则

- 用户资料决定文章的核心观点、范围和叙事方向；
- 不因网络资料不同而静默改写用户观点；
- 明确区分事实、评价、推断和存在争议的说法；
- 日期、人名、乐队名、专辑名和流派名优先核对；
- 中文为主，原文专名保留；
- 不为了篇幅完整而添加与主题无关的百科内容；
- 网络资料必须保留可追溯链接和访问日期；
- 长段原文不直接复制，补充内容使用归纳表述。
- 专辑封面必须记录来源、替代文本和必要的权利说明；
- 首页入选只表示其适合说明时间或关系，不建立“最佳专辑”排名。

## 整理稿状态

| 状态 | 含义 |
| --- | --- |
| 整理中 | 正在拆分、核对和补充 |
| 待确认 | 已完成一轮整理，存在需要用户确认的内容 |
| 可入站 | 内容结构和关键事实已确认，可转换为网站内容 |
