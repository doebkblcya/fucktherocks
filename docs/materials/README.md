# 内容资料

这里存放编辑依据，不定义网站页面或交互。现行产品范围只看 [`../README.md`](../README.md)；页面实际数据只看 `src/data/`。

- [`explorable-rock-map.md`](./explorable-rock-map.md)：时间、分类、关系与代表录音的整理母稿；包含待核对的编辑判断。
- [`explorable-rock-map-sources.md`](./explorable-rock-map-sources.md)：原图校正、文章映射及来源底账。
- [`raw/`](./raw/README.md)：用户提供的原始资料和抓取归档，原则上不改写。

## 入站规则

1. 从原始资料提取时间、地点、声音特征和关系，保留出处与不确定性。
2. 核对名称、形成区间和关系类型；区分事实、评价与推断。
3. 在母稿中整理，再归纳到 `src/data/`；不要直接复制长段原文。
4. 未核实的关系留在母稿，不因图上需要连线而补造父子关系。

资料多不意味着要增加页面。唱片、场景或媒介只有在帮助解释流派的时间发展与分类时才进入网站。
