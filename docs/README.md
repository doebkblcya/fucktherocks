# 文档索引

本目录记录《FuckTheRocks》摇滚音乐知识网站的规划与设计文档。

## 已确认的核心决策

- **产品形态**：综合内容站（百科 + 时间线 + 数据库三合一）
- **技术栈**：Astro + Markdown/MDX 静态站
- **内容范围**：全流派通史（50s 起源 → 当代）
- **分类学**：自由网状深度（有向图，支持多父/融合）
- **交互**：纯只读，无用户系统
- **内容生产**：MusicBrainz 导入结构化数据 + 人工撰写叙事
- **语言**：中文为主，专名保留原文
- **搜索**：Pagefind 本地搜索
- **品牌**：FuckTheRocks（域名 fuckthe.rocks）
