# FuckTheRocks 文档

本目录是第一版产品、设计与实现的事实来源。文档只描述当前确定要完成的内容，不维护旧版功能，也不提前规划远期栏目。

## 当前状态

- 产品范围已经确认；
- 第一版只有首页、探索页和基础错误页；
- 首页视觉方向已收敛为白底黑字的极简现代杂志风，通过全屏球内 3D 专辑画廊建立品牌体验；
- 探索页以 11 段纵向年代和 95 条分类索引为阅读骨架，关系在条目内用文字说明；
- 旧版网站页面、布局、样式和内容模型没有参考价值，已退出后续方案；
- 原始资料、探索图母稿、来源底账和资料处理脚本继续保留；
- 30 张真实专辑封面与根源至当代的探索页已进入可评审原型；探索内容仍需逐条核对，封面权利待公开部署前核实。

## 已确认的第一版路由

~~~text
/          3D 专辑画廊首页
/explore   时间化摇滚关系网络
/404       基础错误页
~~~

历史、分类、流派、乐队、专辑和搜索都是探索页内的内容或操作，不生成独立栏目。流派与事件详情在探索页内打开，可以通过查询参数形成可分享状态。

## 文档结构

| 文档 | 回答的问题 |
| --- | --- |
| `product.md` | 第一版做什么、不做什么 |
| `design.md` | 三个页面如何呈现与交互 |
| `implementation.md` | 使用什么技术、如何降级和验证 |
| `roadmap.md` | 从空白工程到第一版如何推进 |
| `album-covers.md` | 首页 30 张专辑的编辑选择和图片权利状态 |
| `materials/` | 网站内容的原始资料、母稿和来源 |

若文档之间出现冲突，以 `product.md` 的产品范围为准；视觉与交互细节以 `design.md` 为准；代码不得反向定义产品范围。
