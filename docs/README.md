# FuckTheRocks 文档

本目录是第一版产品与实现的事实来源。文档只描述当前要完成的内容，不维护远期功能清单。

当前处于资料整理与确认阶段。内容达到“可入站”状态前，不开始第一版页面重构。

## 已确认方向

- 品牌：FuckTheRocks，域名 fuckthe.rocks；
- 核心内容：一张同时表达摇滚发展路线与流派关系的时间化网络；
- 主要页面：首页、探索；
- 首页：宣传型、视觉优先，在浏览器能力允许时启用高级动效；
- 探索页：年代是阅读骨架，流派关系是可交互网络，历史与分类不再拆成两个栏目；
- 节点详情：在探索页内展开，不为每个流派单独建立页面；
- 视觉：保留复古黑胶车库风；
- 代表专辑：作为时代与流派的关联内容，不形成独立栏目；
- 内容数据来源：进入真实内容编辑阶段后，通过样本实测再确定。
