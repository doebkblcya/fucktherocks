# FuckTheRocks — 第一版实施路线

## 当前状态

产品范围、视觉方向和技术边界已经重新确认：

- 第一版只有 3D 专辑画廊首页、时间化摇滚关系网络和基础错误页；
- 首页采用白底黑字的极简现代杂志风，以全屏球内专辑画廊作为核心视觉；
- 探索页采用纵向时间链、完整名称索引和按需展开的文字关系；
- 旧版网站页面、布局、样式和内容配置不再使用，工程从干净骨架重新建立；
- 原始资料、探索图母稿、来源底账和资料处理脚本继续保留。

不等待全部 175 篇资料完成后才开始设计。早期 1975—1994 切片已完成验证，探索页现已扩展到根源至当代；接下来重点是逐条核对，而不是继续增加默认视觉效果。

## 阶段 0：范围与文档重置

目标：建立唯一、无冲突的第一版定义。

- 将页面范围收敛为首页、探索页和 404；
- 确认首页 3D 专辑球面方向；
- 确认白底黑字、冷峻杂志和雕塑摄影式空间感；
- 确认探索页不拆分历史与分类；
- 明确完整、简化和静态三种能力模式；
- 清除旧版网站实现，保留资料与工程配置。

完成标准：

- `product.md`、`design.md`、`implementation.md` 和 `roadmap.md` 相互一致；
- 旧页面不再被当作设计或代码基础；
- 后续工作只围绕三个路由展开。

状态：已完成。

## 阶段 1：干净工程骨架

目标：从空白实现建立三个可构建页面和新的设计基础。

- 建立 `/`、`/explore` 和 `/404`；
- 建立新的全站布局、字体层级、色彩变量和基础焦点样式；
- 导航只保留品牌和探索入口；
- 建立静态首页占位、探索页内容骨架和完整 404；
- 建立新的 Genre、Era 和 Album 内容集合样本；
- 加入引用检查和基础页面元信息。

完成标准：

- 三个页面均可静态构建；
- 不存在旧版栏目链接和样式残留；
- 无 JavaScript 时可以访问首页入口、探索骨架和 404；
- 示例内容通过 Schema 与引用检查。

## 阶段 2：首页 3D 原型

目标：优先验证第一版风险最高的三维视觉和滚动手感。

- 选择 30 张跨年代真实专辑作为球面原型数据，再根据视觉密度决定是否增减；
- 验证封面来源、展示方式、替代文本和图片规格；
- 使用 Three.js 建立球面螺旋和共享几何体；
- 使用原生滚动进度驱动球内视角沿时间路径环视；
- 使用 GSAP 或阻尼插值控制平滑过渡；
- 相机保持在球心附近，仅做轻微位移，不让镜头翻滚；
- 建立当前年份、专辑与一句话介绍的 HTML 信息层；
- 保持顶部单一探索入口，不增加展览式结尾文案。

同时实现：

- 完整模式；
- 简化模式；
- 静态模式；
- WebGL 初始化失败和 context lost 降级；
- 移动端封面数量、分辨率与运动缩减。

完成标准：

- 球内视角能够读出时间顺序，不是随机图片背景；
- 原生滚动未被劫持；
- 页面加载期间和静态模式下入口始终可用；
- 桌面滚动稳定，移动设备不存在不可接受的卡顿、发热或内存增长；
- `prefers-reduced-motion` 不出现持续三维运动。

## 阶段 3：真实内容切片

1975—1994 年的 Punk、Alternative 和 Metal 切片已经完成原型验证；这一段不再是探索页的全部范围。

## 阶段 4：完整时间链与分类索引

状态：已形成可评审版本。

- 以 11 段历史覆盖根源到当代；
- 将资料母稿中的 95 个流派、场景与相邻传统转换成可搜索索引；
- 仅展示证据较充分的 110 条文字关系，默认不画满屏连线；
- 保留原生 HTML 阅读和 `/explore?genre=...` 深链接；
- 验证桌面、手机、搜索与行内详情。

## 阶段 5：内容核对与边界补强

状态：进行中。当前范围是“主要谱系”，不声称已列尽全球所有子流派。

- 逐条核对形成区间、名称、类型和一句话定义；
- 为入站关系补充逐项来源，并复核融合与场景承接是否被误写成直接衍生；
- 对 2000 年后的地域场景与 2010 年后的发展继续补资料；
- 对暂存于母稿的 C 级编辑假设保持不展示；
- 邀请内容评审确认争议较大的边界后再标记为“可入站”。

## 阶段 6：专辑与事件层

- 将代表专辑与流派、年代事件建立稳定引用；
- 保持首页封面选择与探索页资料一致，但不把探索页变成专辑卡片墙；
- 在时间段的“关键变化”之外，按证据与阅读价值决定是否增加独立事件详情。

## 阶段 7：整合与发布

目标：完成第一版公开访问。

- 完成响应式、可访问性和性能检查；
- 完成首页到探索页的视觉衔接；
- 完成所有模式和失败状态测试；
- 补齐页面标题、描述、规范链接和分享信息；
- 检查封面来源、替代文本和必要权利说明；
- 确定静态托管平台；
- 配置自定义 404；
- 绑定 `fuckthe.rocks`；
- 建立可重复的构建与发布流程。

完成标准：

- 类型检查和生产构建通过；
- 核心浏览路径无断链；
- 低性能设备、无 WebGL、无 JavaScript 和减少动态效果模式可用；
- 首页不阻塞探索入口；
- 404 能把用户带回首页或探索页；
- 域名可访问且发布过程可重复。

## 执行原则

- 每个高风险体验先用最小真实样本验证；
- 首页 3D 场景和探索关系网络分别控制复杂度；
- 内容没有确认来源时，不用视觉效果掩盖不确定性；
- 不为未进入当前阶段的问题提前增加架构；
- 不恢复旧版栏目或组件；
- 每完成一个阶段，同步更新文档中的当前状态。
